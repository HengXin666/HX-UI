## Problem

L5 kits 层缺一组卡片件: 聚光卡, 边缘辉光, 侵蚀卡, 全息卡, 像素卡, 名片卡, 镜面证件卡, 倾斜卡, 文件夹. 行为规格在 docs/research/catalog/components-1.md 与 components-2.md 的 SpotlightCard, BorderGlow, DecayCard, HoloCard, PixelCard, ProfileCard, ReflectiveCard, TiltedCard, Folder 条目里. 目录对其中几件的裁决是 "不做" (着色器场) 或 "借鉴", 计划已由用户确认, 照计划落地. 上游许可不允许移植再分发, 只把条目里的常数, props 和行为描述当规格, 用本库引擎重写, 组件名换成本库自己的.

## Decision

不引 WebGL 与 three. 光斑, 辉光, 箔面与反光用 CSS 渐变, 遮罩与混合模式; 像素网格用 canvas2d; 倾斜, 翻面与托起用 craft 弹簧 (规格的 omega / zeta 经叠放族的 omegaSpring 换算), 指数跟随用族内 follow (规格的 1 - exp(-dt / tau), 帧间隔上限 0.05s). 颜色只用语义 token, color-mix 与 CSS 颜色关键字, 不写色值; 曲线引用 CURVE, 焦点环用 FOCUS_RING. 规格里没给出数值的常数标 "HX 自定". 减弱动效时不倾斜, 不闪光, 不做入场与闲置动画.

着色器才能做到的部分各件段落以 ENGINE-GAP 写明缺什么, 以及补上需要什么.

kits 的总出口 src/kits/index.ts 与 ./kits 子路径在收口一步统一接, 本批只维护本族 index.ts.

## LampCard (规格 Components/SpotlightCard)

聚光卡: 卡面一团光斑追指针, 跟随 tau = 0.015 + smoothing (0.3) × 0.22 s, smoothing 0 直接贴指针 (规格同). 指针在 window 上监听, 卡外 proximity (80px) 内光斑按距离线性渐弱, 再远熄灭. 光斑亮 0.1s 暗 0.32s, 按下闪光起 0.05s 落 0.28s (规格同); 闪光把强度放大 0.6, 尺寸放大 0.15 (HX 自定). 边框用同一光斑经遮罩取 1px 环, 强度 borderGlow (0.6). 光斑直径 spotlightSize (240), 实心段占 1 - softness (0.7), shape 支持 circle 与 ellipse (椭圆纵横比 0.6, HX 自定). 颜色 spotlightTone 为语义色, 按 intensity (0.15) 混入透明. 卡内元素获得焦点时光斑停在卡心. ambient 时无指针也在卡心留 0.35 的弱光 (HX 自定). 减弱动效时光斑直接贴指针, 显隐不过渡, 无闪光. 规格的 theme (dark / light 主题表) 交给 token, grain (噪点) 未做, SHAPES 中 circle 之外的形状只做 ellipse.

## EdgeGlow (规格 Components/BorderGlow)

边缘辉光卡: 指针离卡心的远近按 max(|nx|, |ny|) 记 0..100, 只在离边 edgeSensitivity (30) 以内亮, 强度线性升到 1. 指针方位角正上方 0 度顺时针. 光锥以方位角为中心张角 2 × coneSpread (25 度), 颜色序列 tones (语义色, 默认 primary / accent / secondary) 依次铺在锥内, 用在三层: 1.5px 边框环 (HX 自定), 外侧 glowRadius (40) 柔光 (模糊 glowRadius / 2, 强度 glowIntensity × 0.6, 系数 HX 自定), 内侧沿边的径向遮罩填充 (fillOpacity 0.5, 遮罩起点 70% HX 自定). 出现 0.25s ease-out, 消退 0.75s ease-in-out (规格同), 离开时保留方位. animated 时挂上自演示一次扫边, 时间轴照规格: 远近 500ms 三次缓出升满, 2500ms 后 1500ms 三次缓入落回; 方位 1500ms 三次缓入转到半圈, 再 2250ms 三次缓出转满. 规格无减弱动效, 本件补上: 减弱动效时不演示, 辉光无过渡. 规格的 glowColor (HSL 三元组) 与 backgroundColor, colors (色值数组) 换成语义色 glowTone 与 tones, 底色交给 bg-card.

## TiltCard (规格 Components/TiltedCard)

倾斜卡: 指针在卡上时卡面朝指针倾, 最大 rotateAmplitude (12) 度, 托起到 scaleOnHover (1.05). 倾斜弹簧由 smoothness (0.6) 换算: omega 从 24 降到 8 rad/s, zeta 0.8 (规格只给 smoothness, 换算 HX 自定); 托起弹簧同 omega, zeta 至少 0.85 (规格同). 反光为指针处的径向高光, overlay 混合, 强度 glare (0.5) 乘托起; 投影用 var(--shadow-xl), 浓度 shadow (0.5) 乘托起. 有 backContent 时卡面是 role=button (aria-pressed), 点击 (按下到松开移动不超过 6px, 规格 FLIP_THRESHOLD) 或 Enter / 空格翻面, 翻面弹簧 omega 9.5 zeta 0.72, 按压 26 / 0.8 缩小 0.03 (缩小量 HX 自定); flipped 受控时只回调 onFlip. overlayContent 在 displayOverlayContent 时按 overlayDepth (30px) 浮起. captionText 提示框跟指针 tau 0.035s, 显隐 16 / 1, 按横向速度甩动 (角 = -vx × 0.012, 钳 ±14 度, 速度衰减 tau 0.08s, 弹簧 18 / 0.62), 均照规格. 减弱动效时不倾斜不托起, 翻面直接到位 (规格减弱时翻面改 omega 18, 这里直接落定). 规格的 deviceorientation (陀螺仪倾斜) 与入场淡入 0.45s 未做, glareColor 换成关键字 white 的 color-mix, containerWidth / imageWidth 等分开的尺寸合成 width / height.

## BadgeCard (规格 Components/ProfileCard)

名片卡 (article, aria-label 为姓名): 头像居下, 姓名与头衔居上, 底部信息条 (小头像, @handle, 状态点与状态文字, 联系按钮 onContactClick, contactText "Contact"), showUserInfo 可关. 指针在卡上时卡面倾向指针, 最大 tiltStrength (12) 度; 跟手弹簧劲度 120 阻尼 16, 离开归位 24 / 9 (规格同). 头像逆着指针视差 parallax (8) px, 同用倾斜弹簧. 全息层是语义色序列 holoTones 铺成的 115 度彩带, 尺寸 300%, 位置随指针, color-dodge 混合, 强度 holo (0.8) × (0.25 + 0.5 × 光感); 高光是指针处的白色径向, overlay 混合, 强度 glare (0.5) × 光感; 光感亮 0.12s 暗 0.4s, 光心跟随 tau 0.08s (均 HX 自定, 规格 tau 未摘录). intro 时挂上光从左扫到右再回中, 每段 0.6s (HX 自定). 按下压暗, 滤镜过渡 0.2s ease (规格同). 减弱动效时不倾斜, 无视差与扫光, 光感直接显隐. 规格的 statusColor 换成语义色 statusTone (success), theme / backdropColor 交给 token, iconUrl (图案遮罩) 与移动端陀螺仪倾斜 (enableMobileTilt, mobileTiltSensitivity) 未做.

## PixelBloom (规格 Components/PixelCard)

像素卡: 卡面铺一张 canvas2d 像素网格, 间距 gap, 像素 pixelSize (2), 形状 square / circle / diamond (规格 SHAPES). trigger hover (悬停与聚焦), click (role=button, aria-pressed, 点击或 Enter / 空格切换) 或 always. 激活时从 origin (九个方位, 默认 center) 按距离错峰揭开, 延迟 = 归一化距离 × revealDuration (600ms) 的 85% + 15% 抖动 (抖动比例 HX 自定, 伪随机可复现), 每格 0.26s 长出; 收起时过一半延迟按 0.22s 退场 (规格 APPEAR / EXIT; 退场延迟比例 HX 自定). 揭开后按 speed 闪烁 (0.7 + 0.3 sin, HX 自定), 指针附近 (短边 0.45 内, HX 自定) 按 spotlight (0.5) 放大, 聚光强度升 6/s 降 3/s (规格同); clickPulse 时按下聚光冲到 2 再回 1 (HX 自定). fade 让边缘像素变淡, opacity 为整体透明度. 外发光 glow (0.5) 按 glowTone 随激活出现, box-shadow 过渡 260ms ease (规格同). 像素颜色取语义色序列 tones, 由容器 getComputedStyle 读 CSS 变量后交给 canvas, 代码不写色值. dpr 封顶 2, ResizeObserver 重新布点并保留已揭开程度. intro 时挂上过 introDelay ms 揭开一次再收起. noFocus 时不可聚焦. 减弱动效时无入场与闪烁, 像素直接全显或全隐. 规格 VARIANTS 的各预设数值未摘录, 这里预设 default / calm / dense / still 的间距与速度 HX 自定; theme 交给 token.

## FoilCard (规格 Components/HoloCard)

全息卡: 卡比例 63:88, 透视 1100px (规格同), 宽 width (320), 圆角 radius (14), 边框 frame (4) px 用语义色 foilTone (规格 foilColor 为色值, 换成 token, 默认 muted). 图片上盖一层彩虹箔: 色带取规格着色器的六段光谱 (蓝, 青, 绿, 黄, 橙, 玫红), 这是箔面的物理光谱不随主题, 用 CSS 颜色关键字 royalblue / deepskyblue / lawngreen / gold / darkorange / crimson 逼近, 不写色值函数; 色带按 preset 图案遮罩 (bursts / dots / etch / rings / rays / plain, 图案几何 HX 自定, scale 放大格距), color-dodge 混合, 强度 intensity (0.85) × 0.6, 随倾斜横移 (倾满 tiltMax 时到一端). 边缘一圈彩光 edgeSparkle (0.8), 高光随指针 glare (0.5). 指针在卡上时倾向指针, 最大 tiltMax (14) 度, 放大到 hoverScale (1.04), 跟手弹簧 120 / 16, 归位 24 / 9 (与 BadgeCard 同, 规格 HoloCard 未摘录弹簧数值, 借 ProfileCard 的). idle 时无指针按李萨如漂移, 幅度 tiltMax × 0.3, 周期 7s (HX 自定). 有 backImage 时卡面为 role=button, 点击或 Enter / 空格翻到背面; 否则 role=img, aria-label 为 alt. shadow 用 var(--shadow-xl). 显隐过渡 0.3s ease (规格同). 减弱动效时不倾斜, 不漂移, 翻面直接到位, 箔面停在中位.

ENGINE-GAP: 规格是 WebGL 箔面着色器 (uArt, uTilt, uLight, uPreset): 逐像素程序化图案 (Voronoi 裂纹, 六角片, 星点, 刻线, 射线), 每片按哈希随机亮度 (shine), 按视角与光向算的光谱 (菲涅尔式掠射变色), 卡边按倾斜闪烁的星点, 以及 PRESETS 九种. 本件只有 CSS 渐变遮罩: 图案是规则平铺, 没有逐片随机亮度与裂纹, 光谱只随倾斜整体平移, 不随掠射角变化, 边缘星点是静态彩环. 补上需要一个 WebGL2 片元着色器层 (输入卡图纹理, 倾斜与光向 uniform, 按 preset 生成图案与光谱), 或者预烘焙的图案纹理加 CSS mask-image 与 background-position 联动.

## MirrorCard (规格 Components/ReflectiveCard)

镜面证件卡 (article, aria-label 为姓名), 证件比例 1.586: 金属面是 tintTone 与 var(--card) 按 metalness (1) 拉开明暗的斜向渐变 (色标位置 HX 自定), 印 badge, 状态点 (statusTone, success) 与状态, name, role, idLabel ("ID number") 与 idValue (等宽), 中间放 children. bevel (3) px 内描边用 white 的 color-mix. 有 videoSrc 或 webcam 时把画面镜像放大 1.2, 按 blurStrength (6) × (0.4 + roughness 0.3) 模糊, grayscale (1) 去色, soft-light 混合作反射层, 可播放后按 tau 0.35s 淡入 (规格 FADE_SECONDS); webcam 用 getUserMedia (前置摄像头), 不可用或被拒时回调 onWebcamError, 卸载时停轨. 挂上时一道光 1.4s 从 -30% 扫到 130% (规格 INTRO_MS), 之后随倾斜摆动, 摆幅随 warp (0.6) 放大, 强度 shine (1) (摆幅系数 HX 自定). 指针在卡上时倾向指针, 最大 tiltStrength (12) 度, 跟手 120 / 16, 归位 24 / 9 (规格同); 左上高光 glare (0.5) 随指针在卡上 tau 0.15s 显隐 (HX 自定). 减弱动效时不扫光, 不倾斜, 反射层直接出现. 规格的 statusColor 与 tint 色值换成语义色, theme 交给 token.

ENGINE-GAP: 规格是 WebGL 反射 (uVideo, uCam, uWeights, uLod): 视频或摄像头纹理按卡面法线与 warp 扭曲, 按 roughness 做分级高斯模糊 (uSigma, LOD), 倒角 chamfer 的边缘光照, 金属度下的菲涅尔反射与色调, 视角 VIEW_DISTANCE 900 的透视反射, 以及上下文丢失恢复. 本件的反射层只是平铺镜像的模糊视频, 不随倾斜位移或扭曲, 没有倒角光照与菲涅尔, 粗糙度只是整体模糊. 补上需要 WebGL2 着色器层 (视频纹理, 法线贴图, 分级模糊 mip), 或至少按倾斜给反射层加反向位移 (视差) 近似.

## FrayCard (规格 Components/DecayCard)

侵蚀卡: 宽 width (300) 高 height (400), 图片出血放大 1.24 (规格 BLEED) 后经 SVG 滤镜 (feTurbulence 分形噪声, 层数 detail 5, 频率 0.004 × pattern 4; 再 feDisplacementMap) 位移. 侵蚀量的目标 = 指针速度 / 2000px/s × sensitivity (0.5) + 悬停时 hoverDecay (0.05) + 闲置呼吸 idle (0.35) × 0.15 (周期 4s), 钳到 0..1 (速度换算, 呼吸幅度与周期 HX 自定); 升起 tau 0.08s (HX 自定), 落回 tau = recovery (0.6) s. 位移量 = 侵蚀量 × intensity (0.5) × 60px (HX 自定). flow 让噪声频率随时间漂 (±15%, HX 自定). 图片随指针反向平移, 最大 travel (50) × 0.5 px, 并按横向倾 tilt (10) × 0.25 度, 跟随 tau 0.16s (规格同). scope 为 window (默认) 时在 window 上听指针, card 时只听卡上. grain (0.25) 叠一层去色噪点, overlay 混合. grayscale 去色, radius 圆角, children 叠在图上. 减弱动效时无位移, 平移与倾斜, 只留静态噪点. 规格的 chroma (色散分离) 未做.

ENGINE-GAP: 规格是 WebGL 片元着色器 (uImage, uUnit, uScale, uIdle, uFrequency, uOctaves): 分形噪声逐像素侵蚀卡边 (边缘按 rim 溶解成透明, alpha 软边 0.75 / uUnit), 闲置时边缘缓慢漂移, chroma 分色偏移, 与 SCOPES 的指针场. 本件只有位移, 卡边不溶解, 不透明度不随噪声变化, 没有分色. 补上需要 WebGL2 着色器层 (图片纹理 + 噪声阈值做 alpha 侵蚀 + 三道偏移采样做色散); SVG 滤镜也可以加 feComponentTransfer 把噪声阈值成 alpha 遮罩近似边缘溶解, 但每帧改阈值在大图上很慢.
