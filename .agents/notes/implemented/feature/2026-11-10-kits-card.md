# Agent Note: 卡片族 (kits/card) 用 DOM, CSS 渐变, canvas2d 与 craft 弹簧自写

Status: implemented

Decision-ID: kits-card

- `src/kits/card/LampCard.tsx`, `src/kits/card/parts/lamp-spec.ts` (react-bits Components/SpotlightCard)

- `src/kits/card/TiltCard.tsx`, `src/kits/card/parts/tilted-spec.ts`, `src/kits/card/parts/tilt.ts` (react-bits Components/TiltedCard; tilt.ts 为族内共用倾斜)

## Problem

L5 kits 层缺一组卡片件: 聚光卡, 边缘辉光, 侵蚀卡, 全息卡, 像素卡, 名片卡, 镜面证件卡, 倾斜卡, 文件夹. 行为规格在 docs/research/catalog/components-1.md 与 components-2.md 的 SpotlightCard, BorderGlow, DecayCard, HoloCard, PixelCard, ProfileCard, ReflectiveCard, TiltedCard, Folder 条目里. 目录对其中几件的裁决是 "不做" (着色器场) 或 "借鉴", 计划已由用户确认, 照计划落地. 上游许可不允许移植再分发, 只把条目里的常数, props 和行为描述当规格, 用本库引擎重写, 组件名换成本库自己的.

## Decision

不引 WebGL 与 three. 光斑, 辉光, 箔面与反光用 CSS 渐变, 遮罩与混合模式; 像素网格用 canvas2d; 倾斜, 翻面与托起用 craft 弹簧 (规格的 omega / zeta 经叠放族的 omegaSpring 换算), 指数跟随用族内 follow (规格的 1 - exp(-dt / tau), 帧间隔上限 0.05s). 颜色只用语义 token, color-mix 与 CSS 颜色关键字, 不写色值; 曲线引用 CURVE, 焦点环用 FOCUS_RING. 规格里没给出数值的常数标 "HX 自定". 减弱动效时不倾斜, 不闪光, 不做入场与闲置动画.

着色器才能做到的部分各件段落以 ENGINE-GAP 写明缺什么, 以及补上需要什么.

kits 的总出口 src/kits/index.ts 与 ./kits 子路径在收口一步统一接, 本批只维护本族 index.ts.

## LampCard (规格 Components/SpotlightCard)

聚光卡: 卡面一团光斑追指针, 跟随 tau = 0.015 + smoothing (0.3) × 0.22 s, smoothing 0 直接贴指针 (规格同). 指针在 window 上监听, 卡外 proximity (80px) 内光斑按距离线性渐弱, 再远熄灭. 光斑亮 0.1s 暗 0.32s, 按下闪光起 0.05s 落 0.28s (规格同); 闪光把强度放大 0.6, 尺寸放大 0.15 (HX 自定). 边框用同一光斑经遮罩取 1px 环, 强度 borderGlow (0.6). 光斑直径 spotlightSize (240), 实心段占 1 - softness (0.7), shape 支持 circle 与 ellipse (椭圆纵横比 0.6, HX 自定). 颜色 spotlightTone 为语义色, 按 intensity (0.15) 混入透明. 卡内元素获得焦点时光斑停在卡心. ambient 时无指针也在卡心留 0.35 的弱光 (HX 自定). 减弱动效时光斑直接贴指针, 显隐不过渡, 无闪光. 规格的 theme (dark / light 主题表) 交给 token, grain (噪点) 未做, SHAPES 中 circle 之外的形状只做 ellipse.

## EdgeGlow (规格 Components/BorderGlow)

边缘辉光卡: 指针离卡心的远近按 max(|nx|, |ny|) 记 0..100, 只在离边 edgeSensitivity (30) 以内亮, 强度线性升到 1. 指针方位角正上方 0 度顺时针. 光锥以方位角为中心张角 2 × coneSpread (25 度), 颜色序列 tones (语义色, 默认 primary / accent / secondary) 依次铺在锥内, 用在三层: 1.5px 边框环 (HX 自定), 外侧 glowRadius (40) 柔光 (模糊 glowRadius / 2, 强度 glowIntensity × 0.6, 系数 HX 自定), 内侧沿边的径向遮罩填充 (fillOpacity 0.5, 遮罩起点 70% HX 自定). 出现 0.25s ease-out, 消退 0.75s ease-in-out (规格同), 离开时保留方位. animated 时挂上自演示一次扫边, 时间轴照规格: 远近 500ms 三次缓出升满, 2500ms 后 1500ms 三次缓入落回; 方位 1500ms 三次缓入转到半圈, 再 2250ms 三次缓出转满. 规格无减弱动效, 本件补上: 减弱动效时不演示, 辉光无过渡. 规格的 glowColor (HSL 三元组) 与 backgroundColor, colors (色值数组) 换成语义色 glowTone 与 tones, 底色交给 bg-card.

## TiltCard (规格 Components/TiltedCard)

倾斜卡: 指针在卡上时卡面朝指针倾, 最大 rotateAmplitude (12) 度, 托起到 scaleOnHover (1.05). 倾斜弹簧由 smoothness (0.6) 换算: omega 从 24 降到 8 rad/s, zeta 0.8 (规格只给 smoothness, 换算 HX 自定); 托起弹簧同 omega, zeta 至少 0.85 (规格同). 反光为指针处的径向高光, overlay 混合, 强度 glare (0.5) 乘托起; 投影用 var(--shadow-xl), 浓度 shadow (0.5) 乘托起. 有 backContent 时卡面是 role=button (aria-pressed), 点击 (按下到松开移动不超过 6px, 规格 FLIP_THRESHOLD) 或 Enter / 空格翻面, 翻面弹簧 omega 9.5 zeta 0.72, 按压 26 / 0.8 缩小 0.03 (缩小量 HX 自定); flipped 受控时只回调 onFlip. overlayContent 在 displayOverlayContent 时按 overlayDepth (30px) 浮起. captionText 提示框跟指针 tau 0.035s, 显隐 16 / 1, 按横向速度甩动 (角 = -vx × 0.012, 钳 ±14 度, 速度衰减 tau 0.08s, 弹簧 18 / 0.62), 均照规格. 减弱动效时不倾斜不托起, 翻面直接到位 (规格减弱时翻面改 omega 18, 这里直接落定). 规格的 deviceorientation (陀螺仪倾斜) 与入场淡入 0.45s 未做, glareColor 换成关键字 white 的 color-mix, containerWidth / imageWidth 等分开的尺寸合成 width / height.
