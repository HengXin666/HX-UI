# Tally 发布页 · 生成提示词

> 把这份文件整段交给 Cursor / Claude / Lovable 等工具即可生成同款页面.
> 已有 HX-UI 2 的项目, 直接拷贝 `sites/launch/` 整个目录更快, 这份说明是同一套设计的文字版.

## 接入 (拷贝目录时)
1. `npx shadcn add <registry 地址>/launch.json`, 或手动拷贝 `registry/launch.json` 里列出的文件.
2. 全局样式用 `src/styles/globals.css` (shadcn 主题格式, 另有 success / warning / info / brand 令牌和 `tabular` 工具类).
3. 应用根部包一次 `ThemeProvider` 和 `MotionProvider`, 页面里的动效组件都是 `m.*`, 依赖 LazyMotion.
4. 页面挂载时会给 `<html>` 加 `data-site="launch"`, `art.css` 的暖纸色令牌只在这个属性下生效.
5. 把 `tally/trial-dialog.tsx` 里的 `submitTrial()` 换成你的接口.

## 产品与目标
- 产品: Tally, 面向中国中型企业财务团队的自动对账 SaaS. 把银行流水, 发票, ERP 订单自动配对, 只把有出入的交给人.
- 页面目标: 让财务经理在首屏就看懂"它在干什么", 然后点 **免费试用 14 天** 或 **预约演示**.
- 语气: 像一位靠谱的财务同行在说话. 短句, 具体数字, 不说"赋能 / 智能化 / 一站式".

## 技术栈
React 19 + TypeScript, Tailwind CSS v4, shadcn/ui (Button, Dialog, Input, Label, Sheet, Accordion), Motion (`motion/react`, 只用 transform / opacity), lucide-react 图标, 字体 Inter Variable + 系统中文字体.

## 美术方向
- **纸面与墨色.** 暖白纸色背景 `oklch(0.985 0.004 85)`, 墨色正文 `oklch(0.2 0.008 70)`, 次要文字 `oklch(0.5 0.014 70)`, 发丝线 `oklch(0.905 0.008 85)`. 全站单色, 只有状态点用绿 / 黄 / 红.
- **暗色是夜间的账本:** 偏暖的炭黑 `oklch(0.165 0.006 70)`, 不是冷蓝黑.
- **排版:** 标题字重 500, 字距 -0.03em, 行高 1.06; 首屏标题两句, 第二句用 70% 透明的次要色. 正文 17px. 小标签用等宽字体 ("01 · 产品").
- **版式骨架:** 内容最宽 1200px, 两侧 1px 竖线 (栏线) 贯穿全页; 分区之间 1px 横线, 横竖交点放 11px 的细十字 (仅 ≥1280px 显示). 顶栏, 内容, 页脚左右对齐到同一条栏线.
- **圆角** 10px; 卡片只用发丝线, 不用阴影. 唯一的阴影在首屏产品窗口上.
- **不要:** 渐变字, 光晕, 流光边框, 磁吸按钮, 彩色图标方块, 装饰性的假图表.

## 招牌视觉 (全页只有这一个)
首屏下方的"纸面舞台": 比页面深半档的纸色 `oklch(0.962 0.007 85)` 上铺 8px 发丝网格 (线色为墨色 5% 透明), 顶部圆角, 底边贴着下一段. 舞台里是一个**真实可动的对账工作台** (不是截图):
- 左栏: 公司切换 "蓝鲸物流", 搜索 (⌘K), 导航 待处理 37 / 银行流水 / 发票 / 对账规则 / 报表, 银行账户列表 (招商银行 ··8821 等, 前面绿点).
- 中栏: "银行流水 / 2026 年 3 月", 进度条 "自动核销 1,204 / 1,241 · 97.0%", 表格 日期 / 对方与摘要 / 金额 (等宽, 负数用 − 号) / 匹配凭证 / 状态 (点 + 文字: 已匹配, 待确认, 有差异).
- 右栏: 匹配详情, 上下两张卡 (流水 ↔ 发票), 置信度 98.6, 四个维度的得分条 (金额, 日期, 户名, 摘要), 按钮 "确认匹配" / "拆分".
- 动效: 进入视口约 1.2 秒后, 标为"匹配中"的行每隔 0.9 秒依次变成"已匹配", 进度数字随之增加; 播完停 4 秒再来一轮, 离开视口暂停. 减弱动效时直接显示终态.
- 舞台底部 96px 渐隐到页面底色, 工作台在舞台里被裁切, 像从纸面上长出来.

## 页面结构 (自上而下)
1. **顶栏** (sticky, 56px): 左 Tally 标志 (墨色圆角方块里一个白色 T) + 产品 / 细节 / 客户 / 定价 / 问答 五个页内锚点; 右 主题切换 + 胶囊按钮 "免费试用". 滚动后出现底部发丝线和半透明磨砂底. 手机上链接收进顶部抽屉, 点链接先关抽屉再平滑滚动.
2. **首屏:** 小公告 "新 · 多币种自动对账已上线 →"; 标题 "月底对账，" / "从三天缩到二十分钟。"; 说明 "Tally 把银行流水、发票和 ERP 订单自动配对，只把真正有出入的那几十笔交给你。"; 黑色胶囊主按钮 "免费试用 14 天" + 文字链 "预约演示 →"; 下方招牌舞台.
3. **客户墙:** 一句 "1,800 多家企业的财务团队，每个月底都在用 Tally。" + 4×2 发丝线格子, 每格一个单色字标 (不同字体风格, 同为墨色).
4. **01 · 产品** "重复的交给规则，判断留给你。" 左侧三个可切换的标签 (智能匹配 / 规则引擎 / ERP 回写, 当前项顶部有一条墨线), 右侧对应的产品小视觉 (流水与单据之间依次画出连线; 规则句子与命中数; 回写到金蝶 / 用友 / SAP 的状态).
5. **02 · 细节** "财务会在意的那些事，都做好了。" 3×2 发丝线格子: 23 家银行直连, 多币种与汇差, 拆分与合并, 审批流, 审计留痕, SSO 与权限. 每格一个线性小图标 + 标题 + 一句话.
6. **数字条:** 96.4% 流水自动核销 / 18.6 小时 每人每月节省 / 2,412 万笔 累计处理流水 / 99.95% 服务可用性. 数字进入视口时滚动到位.
7. **03 · 客户** 大号引言 "以前月结要三个人加班三天。现在一个人，一个上午就对完了。" — 王蕾, 蓝鲸物流 · 财务经理; 右侧两组结果: 月结耗时 3 天 → 2.5 小时, 人工确认 −94%.
8. **04 · 定价** "按团队规模付费。" 按月 / 按年 (省 20%) 切换; 三列拼成一张表 (列间 1px 线): 团队版 ¥399 / ¥319, 专业版 ¥1,299 / ¥1,039 (底色深一档, 标 "最多团队选择", 黑色按钮), 企业版 ¥3,999 / ¥3,199 (按钮 "联系销售").
9. **05 · 问答** 左右分栏, 左侧标题吸顶, 下方 "没找到答案？和我们聊聊"; 右侧五条手风琴.
10. **收尾:** "下个月底，" / "准点下班。" + 两个按钮; 右侧一张月结完成卡: ✓ 2026 年 3 月 · 月结完成, 大号 "18 分钟", 上月 2 天 6 小时, 下面四行 流水 / 自动核销 / 人工确认 / 差异.
11. **页脚:** 标志 + 一句话, 两列页内链接, 底部版权行.

## 交互
- 所有 "免费试用" 按钮打开同一个表单弹层: 工作邮箱 (必填, 邮箱格式), 公司名称 (必填). 提交按钮是有状态按钮: 提交中 (小转圈) → 已提交 → 切到成功页 "激活链接已发送, 已发送到 xx@xx"; 失败时按钮变成红字描边 "没发出去，再试一次". 回车可提交, 校验没过时焦点落到第一个出错的输入框.
- "预约演示", "和我们聊聊", 企业版 "联系销售" 打开同一弹层的演示版文案; 定价按钮会把所选套餐和计费周期带进弹层说明.
- 弹层关闭后焦点回到打开它的按钮.
- 提交接口是 `submitTrial()` 占位函数, 换成你的后端即可.

## 质量要求
- 1440 / 768 / 390 三档无横向滚动; 手机上工作台只保留中栏.
- 亮暗两套都要过 WCAG AA 对比度 (红色在暖纸面上要压暗到 `oklch(0.52 0.2 27)`).
- 减弱动效下所有内容直接可见.
- 产品窗口里不要用 main / nav / aside 这类地标标签, 整体标成 `role="region" aria-label="Tally 对账工作台演示"`.
