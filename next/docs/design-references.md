## 共性 (要学的)

1. **大字但不粗.** 首屏 48–96px, 字重多在 400–510, 只有 Attio / Clerk 用到 600–700. 字距一律收紧 (-0.02 ~ -0.06em), 行高 0.95–1.15.
2. **双色段落标题.** Linear / Attio / Cursor / Stripe 的区块标题是一整段话: 第一句前景色, 后面同字号换成灰色. 一个标题同时说清 "是什么" 和 "为什么".
3. **正文小而灰.** 15–18px, 行高约 1.5, 用中灰而不是黑.
4. **控件小.** 按钮 30–43px 高, 顶栏 42–76px, 导航链接 13–14px. 大的是字, 不是控件.
5. **一个招牌视觉, 只一个.** Stripe 的渐变丝带, Vercel 的黑三角, Resend 的 3D 立方体, Cursor 把应用窗口放在油画背景上, Mercury 用整幅摄影. 没有一家用 "满屏光晕 + 网格 + 渐变字" 的组合.
6. **真实产品界面当主角.** Linear / Attio / Cursor 首屏直接是可读的应用界面, 字号和真实产品一致, 不放假图表.
7. **底色不是纯白.** #FAFAFA / #F7F7F8 / #F7F7F4 (暖) 或近黑 #08090A. 纯白只给卡片.
8. **标识墙用真 SVG**, 单行或发丝线网格 (Attio), 单色.
9. **微标签用等宽小字**: Linear 的 `FIG 0.1`, Attio 的 `Platform` 小胶囊.
10. **特性区两种主流**: 左侧竖排条目 + 右侧画面 (Attio "Build pipeline / Convert leads"), 或者带真实 UI 片段的便当格 (Stripe / Clerk / Mercury).

## 避免 (AI 味来源)

- 紫蓝渐变字, 标题下大块模糊光晕, 满屏网格底纹叠光晕.
- 流光边框、闪光按钮、磁吸按钮同时出现.
- 每个特性配一个彩色圆角方块图标.
- 跑马灯证言墙、千篇一律的头像卡.
- 按钮做得又大又亮.
