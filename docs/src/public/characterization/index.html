        项状态依据
        类型 / 设计规约 / 蓝图断言在场gates 分组 lib。README 写明蓝图 38 条断言。
        文档注册表 / 冒烟 / 外壳 / 探针在场registry.mjs 的 docs、browser、probe、guard。

        包代价
        monaco-editor / shiki可选 peer。不装 @hx/ui 的人不会带上它们。编辑器本体仍是这两套。
        @xyflow/react蓝图的运行时。HX 是皮和求值，不是图编辑器本体。
        radix-ui / recharts / ldrs整包原语、图表、41 种 Spin。没有按入口拆预算。

        lucide-react 与 Iconify两套图标。门禁在补「类名写错会静默留白」。
