# HX-UI 动效与门面计划

对照材料:

- react-bits `4dc7b5b`, 见 `docs/research/react-bits.md`
- video-shotcraft `1266a3e`, 见 `docs/research/video-shotcraft.md`
- 被否定的页面: PR #42 的 `docs/face`

这份计划不实现代码. 它规定以后每一个控件和首页的每一镜必须达到的手感. 数字是设计合同, 不是现有代码里的值.

## 1. PR #42 为什么平

直说:

1. 首页的 "镜头" 是五个名字加上一句从 0 淡到 1 的字. 没有预备, 没有过冲, 没有落定后的静止, 没有分层停稳. shotcraft 的发牌卡写明 4px 的预备拍等于没做. 我们的 rise 大约就是那个量级.
2. 持续时间绑在一条 2.6 秒的弧上, 眉标, 标题, 按钮用同一种进入. R5 要求开场只有一个主角. 我们把整列文字都当成主角.
3. 没有指针物理. react-bits 的 Magnet 用 `stiffness 170 / damping 16 / mass 1` 做积分, Dock 用 `mass 0.1, stiffness 150, damping 12` 做连续放大. 我们的按钮是颜色切换.
4. 数字是一个弹簧总数. CountUp 是每位一条 1.2em 的槽, 错峰 `min(70ms, 时长的 40%)`, 弹簧过冲被钳在 0.06, 最后停在整数格. 我们的数字在跳, 但没有位, 没有停格, 所以像计数器演示.
5. 分段切换整页没有拇指的 8 帧. segmented-thumb-hero 规定拇指长于 14 帧像慢动作, 短于 5 帧像瞬移, 按下必须先到 scale 0.86. 我们的分段控件只换内容.
6. 图表没有 "冲出坐标轴". chart-live-moves 的尖峰要顶破刻度再重标. 我们是三条静止的 sparkline.
7. 页面模板嵌在一个 70vh 的框里, 上面还有文档站顶栏. 观众没有 3 秒只看一件事. 框本身就是在说 "这是示例".
8. 全站没有按下, 松开, 聚焦, 禁用, 加载的分态合同. react-bits 自己也缺这套, 所以抄它的入场仍然做不出 "$890,000 打磨过一个旋钮" 的感觉. 那笔钱在状态与状态之间的 40ms 里, 不在背景着色器里.

## 2. 运动令牌

全部时间用毫秒. 弹簧用无单位的 stiffness / damping / mass, 积分和 Magnet 相同: `force = k * x - c * v`, `dt` 用帧时间, 钳在 8ms 到 34ms, 防止切后台后一帧飞出去.

缓动只允许这些名字, 禁止在组件里写裸的 `cubic-bezier`:

| 名字 | 曲线 | 用在 |
|---|---|---|
| `out` | `0.16, 1, 0.3, 1` | 大多数进入, 没有过冲 |
| `in` | `0.7, 0, 0.84, 0` | 离开 |
| `overshoot` | `0.34, 1.56, 0.64, 1` | 指示器, 拇指, 图标弹出. 来自 PillNav 的 700ms 弹出, 我们缩短使用 |
| `punch` | `0.2, 1.25, 0.3, 1` | 主体抬起. 来自 spotlight-hero 的 rise 10 帧 |
| `settle` | `0.3, 0, 0.25, 1.15` | 落地后 4 帧级的轻过冲. 来自发牌卡 |
| `linear` | 线性 | 只用于时钟, 不用于可见位移 |

弹簧只允许三档, 调用时写名字:

| 名字 | stiffness | damping | mass | 手感 |
|---|---|---|---|---|
| `press` | 520 | 32 | 0.8 | 按下, 约 90ms 到 95%, 几乎不振 |
| `thumb` | 220 | 26 | 1 | 指示器滑动. 比 segmented 卡片的 120/14 更稳, 避免连弹三下 |
| `follow` | 170 | 16 | 1 | 指针拖拽, 与 Magnet 默认值相同 |
| `digit` | 由过冲 0.06 反解, 同 CountUp `makeSpring(0.06)` | 数字位, 必须停在格上 |

时长:

| 名字 | ms | 用在 |
|---|---|---|
| `press` | 90 | 按下到 0.97 |
| `release` | 140 | 回到 1, 或弹到 1.01 再收回 |
| `color` | 120 | 只颜色, 不带动位移 |
| `thumb` | 267 | 8 帧. 指示器的标准滑动 |
| `digit` | 700 | 一位数字滚动 |
| `hold` | 1000 | 主角落定后不许再动 |
| `arc` | 3000 | 首页唯一主角的完整弧 |

幅度下限: 预备动作小于 8px 或小于 2% scale 视为没做. 这是发牌卡 "4px 无感" 的网页版.

减弱动效: 时长变 0, 弹簧不积分, 直接写终值. 焦点环仍在. 不允许用模糊代替位移 (模糊在减弱动效里更晕).

## 3. 工艺清单

每个新控件合并前逐条过. 缺一条就不能当完成.

1. 状态画全: 默认, hover, press, release, focus-visible, disabled, loading, read-only (若该控件有只读). 每态有开始和结束的 transform, 阴影, 颜色. 颜色只用语义令牌.
2. 按下与松开是两段, 不是一条 `transition`. 按下用 `press` 弹簧或 90ms. 松开用 140ms, 允许 scale 到 1.012 再在 80ms 内收回 1. 收不回来就不许过冲.
3. 可中断. 在按下的第 40ms 松开, 从当前 scale 和当前速度继续积分, 不从 0 重播. 速度符号保留.
4. 连点. 120ms 内第二次按下, 不重置弹簧, 只改目标. 禁止动画队列堆积.
5. `pointercancel` 与 `pointerup` 同路, 和 PillNav 一样. 指针滑出控件再松开, 不得卡在按下态.
6. 键盘: Tab 进, Enter 或 Space 按下. 聚焦环 2px, 偏移 2px, 颜色 `ring`. 鼠标点击后的焦点可以用 `:focus-visible` 隐藏, 键盘不行.
7. 禁用: 不动画到半透明再停. 120ms 内透明度到 0.45, scale 保持 1, `aria-disabled` 或原生 disabled, 不响应按下.
8. 加载: 宽度不变. 标签用 `visibility` 占位, 指示器绝对定位. 禁止按钮变窄.
9. 位移只用 transform. 阴影可以改, 但模糊半径变化不超过 8px, 否则廉价. 发牌卡的阴影是从 32px 收到 2px, 那是镜头, 控件的 hover 阴影只许 1px 到 6px.
10. 亚像素: 指示器的 left/width 用测量值, 写到 0.5px 对齐 (PillNav 的 `+ 0.5` 阈值). 动画结束写回整数像素或 identity, 防止永远斜 0.3px.
11. 光学对齐: 图标比文字中线高 0.5px 到 1px 时要单独补, 不靠 flex 默认居中假装对齐. 数字用 `tabular-nums`.
12. 错峰若存在, 必须加速或有上限. 禁止无上限的 `index * 60ms`. 参考发牌公式或 CountUp 的 40% 上限.
13. 主角只有一个. 同一视口里过冲曲线最多用在一个元素上.
14. 扫光, 粒子, 玻璃最多一件, 且只在主角, 必须裁在圆角内.
15. 减弱动效下终态立刻可见, 读屏文本不跟着动画走.
16. 无声. 不加载音频. 触感来自 scale 和阴影.
17. 快速切换主题时, 颜色 120ms, transform 不重播入场.

## 4. 五个控件的合同

下面每个都要能让人只看按下那 90ms 就知道被打磨过. 时间从指针落下的一帧算起.

### 4.1 按钮

盒子: 高 32px (md), 水平 padding 12px, 圆角 8px, 1px 边. 标签 14px, 字重 500, 图标 16px, 与标签间隙 6px. 图标光学上移 0.5px.

| 时刻 | scale | y | 阴影 | 说明 |
|---|---|---|---|---|
| 0 静止 | 1 | 0 | 0 |  |
| hover 进入 | 1 | 0 | 0 | 只改背景, 120ms `out`. 不放大. 放大是指示器的事 |
| 按下 0 到 90ms | 1 到 0.97 | 0 到 1px | 0 | 弹簧 `press`. y 是 1px 不是 4px, 超过 2px 像按钮陷进桌子 |
| 按住 | 0.97 | 1px | 0 | 保持, 不呼吸 |
| 松开 0 到 140ms | 0.97 到 1.012 | 1px 到 0 | 0 | 从当前速度继续 |
| 松开 140 到 220ms | 1.012 到 1 | 0 | 0 | 收回. 不到 1 就不算结束 |
| focus-visible | 1 | 0 | 环 2px / 偏移 2px | 与按下可叠加, 环不缩放 |
| disabled | 1 | 0 | 0 | 120ms 到 opacity 0.45, 光标默认 |
| loading | 保持按下前的宽 | 0 | 0 | 标签不可见但仍占位, 圆点 12px 绝对居中, 旋转 800ms 线性, 可被减弱动效停住 |

主按钮和次按钮共用这张表, 只换令牌色. 危险按钮同样, 不另做一种弹跳.

连点: 第二次 `pointerdown` 若 scale 还在 0.99 以上, 目标直接改回 0.97, 速度取当前值的 0.5, 避免越点越深.

### 4.2 开关

轨道 36x20, 圆角全圆, 1px 边. 拇指 16px, 左右内边距 2px, 所以行程 16px. 拇指垂直光学居中, 不额外上移 (圆对圆没有字高问题).

| 时刻 | 拇指 x | 拇指 scale | 轨道色 |
|---|---|---|---|
| 关, 静止 | 0 | 1 | muted |
| hover | 0 | 1 | 边框从 border 到 foreground 的 40%, 120ms |
| 按下 | 0 或 16 | 0.92 | 不变. 90ms `press` |
| 松开并切换 | 0 到 16 或反向 | 0.92 到 1 | 色与拇指同时开始 |
| 拇指滑动 | 267ms | 弹簧 `thumb` | 中点 scale 1.06, 结束前回到 1. 这是 8 帧的网页版 |
| 滑动中再次点击 | 目标反转 | 速度保留 | 不回起点重播 |
| focus-visible | 不动 | 1 | 环画在轨道外 2px |
| disabled | 停在当前侧 | 1 | opacity 0.45, 120ms |
| loading | 不提供 |  | 开关没有加载态. 异步结果用旁边的文字 |

`aria-checked` 在松开的第一帧就翻转, 不等动画结束. 读屏不读动画.

### 4.3 标签指示器

条高 2px, 贴在标签文字下方 6px, 不是贴容器底边 (贴底边会看起来掉出去). 宽等于文字宽, 不是按钮的内容盒宽. 用测量, 字重变化时重测.

滑动 267ms, 曲线 `overshoot`. 宽和 x 分开插值: x 用弹簧 `thumb`, 宽用 180ms `out`, 因为宽的过冲会让条鼓出文字两端. 结束时 x 和宽对齐到 0.5px 网格.

按下当前已选中的标签: 条 scaleY 到 0.7 (仍是 2px 里的视觉压扁), 90ms, 松开回到 1, 140ms. 不左右抖.

换到新标签: 旧标签颜色 120ms 收到 muted, 新标签 120ms 到 foreground. 颜色晚于条的起动 40ms, 让眼睛先看见条再看见字变重. 字重不动画 (字重插值发糊), 只在 120ms 时切到 560.

键盘左右: 与点击同一条滑动. 焦点环在标签上, 不在条上.

快速连按三个标签: 条的目标一直是最后一项, 速度不清零. 禁止三次依次播放.

减弱动效: 条瞬间出现在新文字下, 无过冲.

### 4.4 数字

结构照 CountUp, 不照一个 `textContent` 滚动的总数.

- 每位宽 0.62em, 高 1.2em, `overflow: hidden`, `tabular-nums`.
- 滚动时长 700ms. 多位时错峰 `min(70ms, 700 * 0.4 / (n-1))`. 高位先动.
- 曲线用 `digit` 弹簧, 过冲不超过 0.06 位. 结束必须停在整数格, 残差用 `t^3` 补进, 和 `makeSpring` 相同.
- 外层时钟线性. 在 300ms 时改目标值: 从当前显示的小数位继续走向新目标, 不跳回 0.
- 千分位和小数点不滚动, 它们是静止槽.
- 读屏只宣布终值.
- 减弱动效: 直接终值, 不建条带.
- 加载: 显示末值的骨架, 宽度等于终值宽度, 避免数字到来时把版面挤开.

首页若只有一个大数字, 它就是那一镜的主角, 周围文字在它落定前不许过冲.

### 4.5 分段拇指

这是首页和定价切换要用的控件, 标准直接来自 segmented-thumb-hero, 改成可打断.

- 轨道高 32px, 内边距 3px, 拇指高度 26px, 圆角全圆.
- 按下: 拇指 scale 0.94 (网页上 0.86 太大, 会像故障), 90ms. 同时在点击点起一圈 1px 的线, 12 帧约 200ms 内半径从 4px 到 18px, 透明度 0.35 到 0. 圆心锁点击点, 不跟着拇指.
- 滑动: 267ms, 弹簧 `thumb`. 短于 160ms 禁止 (读作瞬移), 长于 420ms 禁止 (读作慢动作).
- 到位同一帧: 新标签 opacity 从 0.7 到 1, 旧标签到 0.7. 不换字重.
- 拖拽: 若用户按住拇指拖, 改走 `follow` 弹簧, 松开时用当前速度滑向最近一档, 时间仍钳在 160 到 420ms.
- 禁用某档: 拇指不能落到那一档, 最近档吸附, 该标签 opacity 0.4.
- 三项以上: 每段至少 80px, 否则 267ms 内看不清经过了谁.

## 5. 要做的招牌效果

只做这些. 不做 64 个着色器背景.

| 效果 | 技法 | 合同 |
|---|---|---|
| 指针跟随 | Magnet 积分, `follow` 弹簧, padding 衰减 | 只给首页的那一张记录卡, 不给导航 |
| 发牌入场 | `cue(k) = a + b k - c k^2`, c 取正 | 组件网格的第一屏, 满板后 hold 500ms |
| 按位数字 | CountUp 槽 + `digit` 弹簧 | 指标, 价格 |
| 拇指 | 第 4.5 节 | 定价和整页切换 |
| 坐标轴冲击 | 值越过 domain 时网格用 200ms 重标, 线不重头画 | 一个图表演示, 不是每张图 |
| 单主角推近 | 3s 弧, `punch` 抬起, hold 1s, 阴影滞后 80ms | 首页第一镜, 全页只有这一次过冲 |
| 文字三拍 | BlurText 的中点 scale 0.97, 模糊从 8px 到 0, 总长 500ms | 只用于一句引语, 不用于按钮标签 |

明确不做: 全屏 Aurora, 鼠标流体, 每卡扫光, 毛玻璃默认表面, 逐字解密当正文, three 布料.

## 6. 首页分镜

空 URL. 一镜一件事. 30fps 换算只用于对照 shotcraft, 实现用毫秒和滚动进度. 滚动进度必须可逆: 往回滚, 相位跟着减, 不重播.

**镜 0, 0 到 300ms, 静止.** 顶栏已在. 主角句不在. 避免第一帧所有东西一起出现.

**镜 1, 主角, 3000ms 弧加 1000ms hold.** 唯一一句: "先把一页排完." 字号用展示令牌. 0 到 200ms 先下沉 8px (预备, 过肉眼阈值), `in`. 200 到 900ms 用 `punch` 抬回并过冲到 y=-4px, scale 1.02. 900 到 1400ms 用 `settle` 回到 y=0, scale 1. 1400 到 2400ms 完全不动. 旁边的记录卡在 2400ms 才允许开始, 而且只用 `out`, 不许过冲. 顶栏不参加.

**镜 2, 记录卡, 滚动 0 到 0.25.** 卡从 x=32px 收到 0, 700ms 等价的滚动映射. 指针进入卡片后改 Magnet, 离开后速度保留地回到 0. 卡内三行字不各自入场.

**镜 3, 发牌说明, 滚动 0.25 到 0.45.** 三张说明卡按发牌公式进入, 间隔从 120ms 收到 40ms. 最后一张落地后整组 hold. 阴影比卡片晚 80ms 从 8px 收到 2px.

**镜 4, 拇指切换整页, 滚动 0.45 到 0.7.** 分段控件使用第 4.5 节. 切换田野和窑四号时, 旧页 x 到 -24px 同时 opacity 到 0, 180ms `in`. 新页从 x=24px 到 0, 267ms `thumb`. 两页交叉 80ms. 不使用淡入整页.

**镜 5, 一个数字, 滚动 0.7 到 0.85.** 只有一个按位数字, 700ms, 错峰受 40% 上限. 旁边不放三个等大指标卡. 三个等大卡是 #42 的样子.

**镜 6, 组件入口, 滚动 0.85 到 1.** 分组名发牌进入, 无过冲. 点击用第 4.1 节的按钮合同. 最后 1 秒滚动停住时页面不再动.

顶栏在所有镜里都用第 4.1 和 4.3 的合同, 不另做一套 "营销按钮".

窄屏: 镜 1 的卡改到句子下面, 预备仍是 8px. 镜 4 的两页上下叠, 不用左右飞. 拇指仍是 267ms.

暗色: 只换令牌. 不重播镜 1.

## 7. 文档站怎么展示效果

组件页保持 hash, 例如 `#/button`. 页结构改成三截, 而不是长文加一个不能动的预览.

1. 舞台. 默认态. 舞台本身不入场动画, 避免和控件抢戏.
2. 道具台. 每个数值 props 一条滑杆或开关: 时长, 过冲, 禁用, 加载. 改值立刻作用在舞台上, 不重新挂载, 这样能看见中断. 滑杆使用第 4.5 的拖拽手感.
3. 源码. 与当前道具台的值一致, 一键复制. 复制的是调用代码, 不是库的内部文件.

列表页只显示名字和一句 "它的 90ms 是什么". 不自动播放 WebGL.

搜索仍然是 `⌘K`. 主题三态不改行为.

## 8. 实现顺序

1. 令牌和弹簧积分放进运动模块, 带中断和减弱动效. 没有这个, 后面全是假的.
2. 用第 4 节重做按钮, 开关, 标签条, 数字, 分段拇指. 每件先过第 3 节清单.
3. 首页按第 6 节重拍. 删掉现在的五颗名字按钮和三列等大指标.
4. 文档舞台和道具台先覆盖这五件, 再扩展到别的控件.
5. 着色器和发牌网格最后做, 而且首页同时只留一个.

不做的事: 不把 react-bits 的 183 件移植进来. 不把 Remotion 时间轴嵌进按钮.

## 9. 全量阅读之后

逐件记录在 `react-bits.md` 与 `video-shotcraft.md`, 勾选在 `coverage.md`. 183 个组件目录的四种源码口味都读过 (1070 个源文件). 226 个 Remotion 演示和 124 张镜头卡都读过. 另外读了 Micro 35 件. 第一遍没把 Micro 算进 183, 那一层才是控件手感.

读完以后合同只改这几处, 第 4 节的时间表不变:

- SquishSwitch 的按下是 stiffness 320, damping 40, mass 0.6, 滑动是 stiffness 520, damping 34. 我们的 `press` 用 520 / 32 / 0.8, 比他们的按下更硬. 保留. 网页按钮要比镜头弹簧快, 不能把 3 秒弧线用在按下上.
