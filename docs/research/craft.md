# 控件分态合同

数字是实现合同. 时间是毫秒. 弹簧是 stiffness / damping / mass. 缓动只许用名字, 定义在运动令牌里, 组件不写裸的 cubic-bezier.

令牌:

| 名字 | 曲线或弹簧 | 用途 |
|---|---|---|
| out | 0.16, 1, 0.3, 1 | 进入, 无过冲 |
| in | 0.7, 0, 0.84, 0 | 离开 |
| overshoot | 0.34, 1.56, 0.64, 1 | 指示器, 图标弹出 |
| punch | 0.2, 1.25, 0.3, 1 | 主体抬起 |
| settle | 0.3, 0, 0.25, 1.15 | 落地后的轻过冲 |
| press | 520 / 32 / 0.8 | 按下, 约 90ms 到 95% |
| thumb | 220 / 26 / 1 | 指示器滑动 |
| follow | 170 / 16 / 1 | 指针拖拽 |
| digit | 过冲上限 0.06 | 数字位, 必须停在格上 |

时长: press 90, release 140, color 120, thumb 267, digit 700, hold 1000. 积分 dt 钳在 8ms 到 34ms. 减弱动效时时长变 0, 直接写终值, 焦点环仍在.

共用规则: 按下与松开是两段. 可中断, 从当前值和当前速度继续, 不从 0 重播. 120ms 内再次按下只改目标. pointercancel 与 pointerup 同路. 焦点环见下方「焦点环与线宽」. 禁用 120ms 内透明度到 0.45, scale 保持 1. 位移只用 transform. 颜色只用语义令牌. 线宽 1px.

### 焦点环与线宽

焦点环统一写成 outline 1px, outline-offset 2px, 颜色 ring. 本文早先写的 "焦点环 2px" 指环的厚度, 与门禁 (ui-rules) 管的 border / ring / outline / divide 线宽 1px 冲突; 裁定按门禁走 1px, 不改 rules, 不改 baseline.
可见度靠两样补足, 不靠加粗: ring 用深一档的语义色, 2px 的偏移让环和控件边之间留出一圈底色.
用 outline 不用 box-shadow 的 ring: outline 不占布局, 不被 overflow 裁掉, 也不跟着 transform 缩放, 正好满足 "环不跟着缩放".
代码里只引用 craft/tokens.ts 的 FOCUS_RING, 不各自拼串. 已提交的老控件仍是 ring-1, 收口时统一换成 FOCUS_RING.

## 数字

## 选择

## 提示

显示延迟 400ms, 离开延迟 80ms. 进入 140ms out, y 从 4px 到 0, opacity 0 到 1, 无过冲. 离开 80ms in. 快速移到相邻触发器时, 旧提示不重播, 只改位置, 267ms thumb. 减弱动效下直接出现, 无延迟以外的等待可以保留 400ms (那是信息节奏, 不是位移). 不抢焦点.

## 对话框

遮罩 180ms opacity 0 到 1, out. 面板 200ms, scale 0.98 到 1, y 8px 到 0, overshoot 只给面板一次. 关闭反向, 140ms in, 无过冲. 打开未完成时按 Esc, 从当前 scale 走向关闭, 不先播完打开. 焦点落在面板内第一个可聚焦元素, 环使用同一套 outline 1px + 偏移 2px. 背景滚动锁住. 减弱动效下面板直接在终态.

## 首页镜头

实现用毫秒和滚动进度, 进度可逆.

- 镜 0, 0 到 300ms, 静止. 顶栏在, 主角句不在.
- 镜 1, 3000ms 弧加 1000ms hold. 唯一一句. 0 到 200ms 下沉 8px. 200 到 900ms punch 到 y=-4px, scale 1.02. 900 到 1400ms settle 回 1. 1400 到 2400ms 不动. 记录卡 2400ms 后才用 out 进入.
- 镜 2, 滚动 0 到 0.25. 卡从 x=32px 到 0. 指针进入后 follow 弹簧, 离开速度保留地回 0.
- 镜 3, 滚动 0.25 到 0.45. 三张卡发牌, 间隔从 120ms 收到 40ms. 阴影晚 80ms, 从 8px 收到 2px.
- 镜 4, 滚动 0.45 到 0.7. 分段拇指. 旧页 x=-24px, opacity 0, 180ms in. 新页 x=24px 到 0, 267ms thumb. 交叉 80ms.
- 镜 5, 滚动 0.7 到 0.85. 一个按位数字, 700ms.
- 镜 6, 滚动 0.85 到 1. 分组名发牌, 无过冲. 按钮走按钮合同.

窄屏镜 4 改为上下叠, 不用左右飞. 暗色只换令牌, 不重播镜 1.
