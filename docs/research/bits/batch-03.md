- 看起来: 两条价值噪声带用指数 smooth-min 合成, 沿流向以 `200*speed` 的速度平移. 指针把附近像素转一个小角, 亮带在指针处被拉亮. 按下在落点转一个漩涡, 0.23 秒到顶后按 `exp` 衰减, 6 秒后角度归零. 开场 1.8 秒能量从 0 涨满.
- 技法: 手写 WebGL2 全屏三角形. 插值用 `sin` 形 lerp, 两场用 `smin`. 磁铁位置是指数跟随, 没有速度项. 不用 three / GSAP / motion.
- 常数: `MAX_COLORS=8`, `INTRO_SECONDS=1.8` (`FluxLines.jsx:6-7`). `sinlerp` 用 `sin(w*π-π/2)` (`:28-29`). 五偏移噪声权重 `2, 1.5, 1.25, 1.125, 1`, 和 `7` (`:51`). 参考尺度 `700/max(scale, 0.05)` (`:91`). 流速 `spd=200*speed` (`:111`). 横向扭曲格子 `60` 与 `120`, 幅度 `50` 与 `100` 再乘 turbulence, 种子 `10` 与 `15` (`:115-116`). 峰格子 `40`, 种子 `1` 与 `0`, 沿流向再乘 `0.5` (`:117-118`). `smin` 的 `k=max(fluidity, 0.001)` (`:23-25`, `:119`). 等值线在 `0.4` (`:122`). 半带宽 `rimWidth*0.5`, 像素半宽上限 `28*ratio` (`:124`, `:320`). 带 `5*rimWidth*(1-across)` (`:126`). 磁铁转角 `pull*0.55`, `pull=strength*exp(-dot/radius²)` (`:94-96`). 漩涡 `1.9*min(1, age/0.23)*exp(-max(0, age-0.23)*1.1)`, 半径 `height*0.22*(1+age*0.5)`, `age<6` 才给角度 (`:325-326`). 闪烁格子 `60` 种子 `12`, 被磁铁压到 `1-reveal*0.75` (`:128`). 核心 `smoothstep(line±0.75, pixels)` (`:131`). 揭开 `reveal²(3-2*reveal)`, 每秒加 `1/1.8` (`:327`, `:344`). 跟随 τ 是 `mouseDampening` 秒, 默认 `0.15`; 为 0 则一帧贴上 (`:202`, `:348`). 激活 τ `0.3` 秒, 误差 `<0.001` 贴齐 (`:354-355`). `dt` 钳制 `0.0005-0.05` 秒, 首帧 `1/60` (`:339`). 停帧条件: `motion=0` 且激活已贴目标且揭开完成且漩涡年龄 `≥6` (`:358-359`). 默认 `speed=0.5`, `scale=1.6`, `fluidity=0.1`, `rimWidth=0.2`, `sharpness=2.5`, `shimmer=1.5`, `glow=2`, `mouseRadius=0.35` (`:188-201`). 钳制 scale `≥0.05`, fluidity `≥0.001`, rimWidth `≥0.001`, sharpness `≥0.1`, mouseRadius `≥0.01` (`:221-233`). - 指针/滚动: `window` `pointermove` / `pointerdown` / `pointerup` / `pointercancel` 都是 passive, `documentElement` `pointerleave` (`:430-434`). 坐标乘画布/CSS 宽度比, y 从底部量 (`:378-385`). 刚进入且激活 `<0.05` 时把磁铁钉住 (`:391-393`). 按下不看 `button`, 把漩涡年龄写成 0. `pointerup` 与 `pointercancel` 同路: 非鼠标把 `inside` 置假 (`:407-408`). 离开后位置停住, 激活按 0.3 秒回到 0. 无滚动.
- 可中断: 磁铁没有速度, 目标变了按 τ 继续. 新的按下直接覆盖漩涡位置和年龄, 不排队. `paused` 或减弱动效令 `motion=0`, 场时间停, 但漩涡年龄仍每帧加 `dt` (`:341-343`). 忙完才停 rAF.
- 性能: 离屏或 `document.hidden` 不再排 rAF (`:337`, `:363`). 场停,磁铁贴齐,漩涡满 6 秒后也停 (`:358-360`). DPR 上限 2. 监听每实例挂在 `window`. 每帧只画一个全屏三角形.

- 裁决: 不做. 全屏流线与控件状态无关; HX-UI 不要搬 `smin` 场, 漩涡那组 `1.9 / 0.23 / 1.1` 也留在这条背景里.

### Backgrounds/Galaxy

- 文件: `Backgrounds/Galaxy/Galaxy.jsx` 591 行, `Galaxy.css` 14 行 (只定位画布, 无动画). 无变体.
