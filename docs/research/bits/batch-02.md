### Animations/LogoLoop

- 文件: `Animations/LogoLoop/LogoLoop.jsx` 1098 行, `LogoLoop.css` 208 行. 无变体.
- 看起来: 标志沿一条环带循环平移, 布局可弯成波浪,圆弧或绕圈. 入场按位置错峰淡入并下落回位, 悬停可暂停或局部放大, 拖拽跟手后甩出, 步进时停在相邻一项.

CSS: 内容 `opacity/filter/color 0.35s ease` (`LogoLoop.css:85-88`); 节点 `transform 0.3s cubic-bezier(0.4, 0, 0.2, 1)`, 悬停 `scale(1.2)` (`:118`, `:123`); 提示 `0.25s ease`, 初始 `translate: -50% 4px`, 悬停 `opacity: 0.8` (`:151-155`, `:169`). 默认 `speed=120`, `logoHeight=28`, `gap=32`, `fadeOutWidth=0.12`, `bend=0.5`, `scrollBoost=0` (`LogoLoop.jsx:883-903`). `pauseOnHover` 缺省时悬停目标速度为 `0`, 只有 `pauseOnHover===false` 才不暂停 (`:921`). `muted` 钳制 `0-1`, 灰度 `min(1, amount*2)`, 透明度 `1-amount*0.6` (`:1049`, `:1060-1061`).

### Animations/Magnet

- 性能: 静止后停 `rAF` 并把 `last` 置 `0` (`:194-195`). 无离屏观察, 无 DPR 上限. `pointermove` / `scroll` / `pointerleave` / `blur` 全实例一份, 注册表空了才摘掉 (`:52-71`, `:215-218`). 每子步 `Object.keys` 分配, 每帧 `getBoundingClientRect` 和一条 transform 字符串.
- 减弱动效: 挂载时读一次 `matchMedia('(prefers-reduced-motion: reduce)')`, 为真则 `measure` 永远不接合, 不订阅 `change` (`:116`, `:139`).
- Props: `children` `padding=100` `disabled=false` `magnetStrength=2` `maxOffset` `exclusive=true` `axis='both'` `tilt=0` `scale=1` `spring` `onActiveChange` `wrapperClassName=''` `innerClassName=''` `style` 以及其余透传到外层.
- 裁决: 采用. 半隐式欧拉,120Hz 子步和多实例互斥最近者值得进运动层; 触摸被整段丢掉, 减弱动效只在挂载时采样, 这两处不要照搬.
